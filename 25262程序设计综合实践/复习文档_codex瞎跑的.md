## 2. OJ 基础与做题习惯

这一部分最基础，但很容易被忽略。很多题不是不会，而是栽在输入输出和边界处理上。

### 2.1 常见判题结果

- `CE`：编译错误。常见于变量没定义、数组越界导致编译器报错、缺头文件。
- `WA`：答案错误。最常见，通常是边界、特判、状态转移、排序顺序、初始化问题。
- `TLE`：超时。算法复杂度不够好，或者有无意义重复计算。
- `MLE`：超内存。数组开太大、重复开大结构、前缀数组和原数组都保留却没必要。
- `RE`：运行错误。除零、访问非法下标、递归过深、空指针、未初始化。
- `PE`：格式错误。多空格、多空行、缺换行、大小写不符。

### 2.2 输入输出常见形式

- 单组数据：直接读一次。
- 多组数据且第一项给组数：先读 `T`，循环处理。
- 多组数据直到 EOF：`while (cin >> x)`.
- 多组数据直到特殊结束标记：如读到 `0 0 0` 结束。

### 2.3 基本编码习惯

- 先看数据范围，再决定算法。
- 写之前先判断是：
  - 模拟
  - 贪心
  - 搜索
  - DP
  - 数据结构
  - 数论
- 优先想“状态是什么、怎么转移、复杂度多少”。
- 写完后至少检查：
  - 数组是否越界
  - 是否需要 `long long`
  - 多组数据是否重置
  - 输出格式是否严格一致

## 3. 基础算法思想

### 3.1 枚举

适用于数据范围较小，或者答案结构简单、可以直接尝试所有情况。

核心思路：

- 不漏
- 不重
- 能剪枝就剪枝

常见形式：

- 枚举区间左右端点
- 枚举三元组 / 四元组
- 枚举状态
- 枚举答案后验证

### 3.2 模拟

模拟题本质是“按题意一步一步做”。难点往往不是算法，而是细节。

复习重点：

- 是否有隐藏状态
- 操作顺序能不能交换
- 是否需要开结构体保存对象属性

### 3.3 排序

排序题通常不是只考 `sort`，而是借排序做预处理或贪心。

常见用途：

- 先排序再贪心
- 排序后去重
- 排序后双指针
- 排序后更容易剪枝

### 3.4 贪心

不是所有局部最优都能推出全局最优，所以贪心题重点在“为什么这样选是对的”。

常见判断方式：

- 排序后局部决策是否能交换证明
- 是否满足“当前最优不影响后续最优”

## 4. 常用技巧

这一块来自第二次课，实战里非常常见。

### 4.1 尺取法 / 双指针

适用于区间满足某种单调性质时。

常见模型：

- 求满足条件的最短区间
- 求满足条件的最长区间
- 统计满足条件的区间个数

典型特征：

- 左右指针都只向前走
- 时间复杂度通常从 `O(n^2)` 降到 `O(n)`

### 4.2 前缀和

定义：

- `pre[i] = a[1] + a[2] + ... + a[i]`

作用：

- 快速求区间和
- 结合哈希 / map 统计某些性质

常见公式：

- 区间 `[l, r]` 的和为 `pre[r] - pre[l - 1]`

### 4.3 差分

适用于频繁区间修改、最后统一还原。

定义：

- `diff[i] = a[i] - a[i - 1]`

区间加法：

- 对 `[l, r]` 加 `x`
- 只要做 `diff[l] += x`，`diff[r + 1] -= x`

最后前缀恢复原数组。

### 4.4 离散化

当数值范围很大，但真正出现的值很少时，把值压缩到连续下标。

典型流程：

1. 收集所有值
2. 排序去重
3. 用下标代替原值

常见用途：

- 树状数组
- 线段树
- 坐标范围很大但点很少的问题

### 4.5 `struct` 结构体

当一个对象有多个属性时，用结构体管理更清晰。

例如：

- 一个点：`x, y`
- 一件物品：`w, c, group`
- 一条边：`to, next, w`

代码例子：

```cpp
struct Node
{
    int x;
    int y;
    int step;
};

struct Item
{
    int w;
    int c;
    int group;
};
```

如果要排序，通常自己写比较函数：

```cpp
struct Item
{
    int w;
    int c;
};

bool cmp(Item a, Item b)
{
    if (a.w != b.w) return a.w < b.w;
    return a.c < b.c;
}
```

#### `vector`

最常用的动态数组。

常见操作：

```cpp
vector<int> a;

a.push_back(3);       // 尾插
a.push_back(5);
a.pop_back();         // 删除最后一个元素

cout << a.size() << endl;   // 长度
cout << a.empty() << endl;  // 是否为空

for (int i = 0; i < a.size(); i++)
    cout << a[i] << " ";
cout << endl;
```

初始化方式：

```cpp
vector<int> a(10);          // 10 个元素，默认 0
vector<int> b(10, -1);      // 10 个元素，全部是 -1
vector<vector<int>> g(n + 1);
```

排序与去重：

```cpp
sort(a.begin(), a.end());

a.erase(unique(a.begin(), a.end()), a.end());
```

反转：

```cpp
reverse(a.begin(), a.end());
```

pair<int, int> p;

    cout << s[i] << " ";

#### `sort`

默认升序：

```cpp
sort(a.begin(), a.end());
```

降序：

```cpp
sort(a.begin(), a.end(), greater<int>());
```

自定义排序：

```cpp
bool cmp(int a, int b)
{
    return a > b;
}

sort(a.begin(), a.end(), cmp);
```

结构体排序：

```cpp
bool cmp(Item a, Item b)
{
    if (a.w != b.w) return a.w < b.w;
    return a.c > b.c;
}
```

---

#### `lower_bound` 与 `upper_bound`

要求序列有序。

```cpp
sort(a.begin(), a.end());

int pos1 = lower_bound(a.begin(), a.end(), x) - a.begin();
int pos2 = upper_bound(a.begin(), a.end(), x) - a.begin();
```

含义：

- `lower_bound`：第一个 `>= x` 的位置
- `upper_bound`：第一个 `> x` 的位置

常用于：

- 二分查找
- LIS 二分优化
- 统计某个值出现次数

---

#### `set` 与 `map`

`set`：自动有序、自动去重。

```cpp
set<int> s;
s.insert(3);
s.insert(1);
s.insert(3);

cout << s.size() << endl;   // 2

if (s.count(1)) cout << "yes\n";
s.erase(1);
```

`map`：键值对映射，自动按 key 有序。

```cpp
map<string, int> mp;
mp["alice"] = 95;
mp["bob"] = 88;

cout << mp["alice"] << endl;

if (mp.count("cat") == 0) cout << "not found\n";
```

遍历：

```cpp
for (auto it = mp.begin(); it != mp.end(); it++)
    cout << it->first << " " << it->second << endl;
```

如果只想要哈希表效果，也可以用 `unordered_map` / `unordered_set`，但考试里普通 `map`、`set` 更稳。

## 5. 基础数据结构

### 5.1 栈

特点：

- 后进先出

应用：

- 括号匹配
- 表达式处理
- 单调栈
- DFS 非递归实现

#### STL 中 `stack` 的基本用法

头文件：

```cpp
#include <stack>
```

定义：

```cpp
stack<int> st;
```

常见操作：

```cpp
st.push(3);         // 入栈
st.push(5);

cout << st.top() << endl;   // 访问栈顶，当前是 5

st.pop();           // 弹出栈顶

cout << st.top() << endl;   // 当前是 3

cout << st.size() << endl;  // 栈中元素个数
cout << st.empty() << endl; // 是否为空
```

注意：

- `stack` 只能访问栈顶，不能像数组一样随机访问。
- 使用 `top()` 前要确保栈非空。

括号匹配例子：

```cpp
string s;
cin >> s;

stack<char> st;
bool ok = true;

for (int i = 0; i < s.size(); i++)
{
    if (s[i] == '(') st.push('(');
    else
    {
        if (st.empty())
        {
            ok = false;
            break;
        }
        st.pop();
    }
}

if (!st.empty()) ok = false;
cout << (ok ? "yes" : "no") << endl;
```

### 5.2 队列

特点：

- 先进先出

应用：

- BFS
- 多源最短路
- 单调队列

#### STL 中 `queue` 的基本用法

头文件：

```cpp
#include <queue>
```

定义：

```cpp
queue<int> q;
```

常见操作：

```cpp
q.push(10);          // 入队
q.push(20);

cout << q.front() << endl;  // 队头
cout << q.back() << endl;   // 队尾

q.pop();             // 弹出队头

cout << q.front() << endl;
cout << q.size() << endl;
cout << q.empty() << endl;
```

BFS 例子：

```cpp
queue<pair<int, int>> q;
q.push({sx, sy});
vis[sx][sy] = 1;

while (!q.empty())
{
    pair<int, int> now = q.front();
    q.pop();

    int x = now.first;
    int y = now.second;

    for (int k = 0; k < 4; k++)
    {
        int nx = x + dx[k];
        int ny = y + dy[k];
        if (合法且没访问过)
        {
            vis[nx][ny] = 1;
            q.push({nx, ny});
        }
    }
}
```

### 5.3 双端队列 `deque`

`deque` 可以头尾都插、都删。

```cpp
deque<int> q;

q.push_back(3);
q.push_front(1);
q.push_back(5);

cout << q.front() << endl;  // 1
cout << q.back() << endl;   // 5

q.pop_front();
q.pop_back();
```

它是单调队列的常用底层容器。

### 5.4 单调队列

你做过的典型题：

- `练习4/A.cpp`：Sliding Window

用途：

- 维护滑动窗口最值

核心思想：

- 队列里存下标
- 保证队列中的值单调
- 队头始终是当前窗口答案

最小值模板：

```cpp
deque<int> q;

for (int i = 1; i <= n; i++)
{
    while (!q.empty() && q.front() <= i - k)
        q.pop_front();

    while (!q.empty() && a[q.back()] >= a[i])
        q.pop_back();

    q.push_back(i);

    if (i >= k)
        cout << a[q.front()] << " ";
}
```

### 5.5 单调栈

常用于：

- 找左边第一个更大 / 更小
- 找右边第一个更大 / 更小
- 柱状图最大矩形

例子：求每个元素左边第一个比它大的位置

```cpp
stack<int> st;

for (int i = 1; i <= n; i++)
{
    while (!st.empty() && a[st.top()] <= a[i])
        st.pop();

    if (st.empty()) left_big[i] = 0;
    else left_big[i] = st.top();

    st.push(i);
}
```

### 5.6 ST 表 / RMQ

适用于静态区间最值查询。

特点：

- 预处理 `O(n log n)`
- 查询 `O(1)`
- 不能高效修改

常见场景：

- 多次查询区间最大 / 最小值

## 6. 树、堆、图

### 6.1 二叉树基础

重点内容：

- 左子树、右子树
- 前序：根左右
- 中序：左根右
- 后序：左右根

### 6.2 二叉树重建

你做过的典型题：

- `练习4/B.cpp`

结论：

- 前序第一个节点一定是根
- 在中序里找到根后，左边是左子树，右边是右子树
- 递归处理即可

### 6.3 堆

堆本质是“可以快速取最大值 / 最小值”的完全二叉树。

常见操作：

- 插入
- 删除堆顶
- 建堆

应用：

- 优先队列
- Top K
- Dijkstra

#### STL 中 `priority_queue` 的基本用法

默认大根堆：

```cpp
priority_queue<int> q;

q.push(3);
q.push(7);
q.push(1);

cout << q.top() << endl;  // 7
q.pop();
cout << q.top() << endl;  // 3
```

小根堆：

```cpp
priority_queue<int, vector<int>, greater<int>> q;
```

存 `pair`：

```cpp
priority_queue<pair<int, int>> q;
q.push({5, 2});
q.push({3, 7});
```

如果是最短路里常写成：

```cpp
priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> q;
```

表示按 `pair` 的第一关键字从小到大弹出。

### 6.4 图的存储

常见三种：

- 邻接矩阵：简单，但空间大
- 邻接表：最常用
- 链式前向星：竞赛常用，适合静态图

### 6.5 图的遍历

两大核心：

- DFS
- BFS

连通性、最短步数、状态搜索，本质都能往这两类靠。

## 7. 搜索：DFS、BFS 与剪枝

这部分是第五、第六次课的核心，也是实战中最容易考的一块。

### 7.1 DFS

适用于：

- 枚举所有方案
- 回溯
- 连通块搜索
- 组合 / 排列 / 子集问题

模板思想：

1. 定义状态
2. 找结束条件
3. 枚举下一步
4. 回溯恢复

### 7.2 BFS

适用于：

- 无权图最短路
- 状态图最少操作次数
- 从起点一层一层扩展

核心性质：

- 第一次到达某个状态时，步数最少

### 7.3 DFS 与 BFS 怎么选

如果题目问：

- “能不能找到一种方案”  
  一般 DFS 可以做。

- “最少多少步”  
  优先想 BFS。

- “把所有方案列出来”  
  通常是 DFS。

### 7.4 连通块

你做过的典型题：

- `练习4/C.cpp`：Lake Counting

核心：

- 遍历每个点
- 如果是未访问目标点，就从它开始 BFS / DFS
- 搜完这一整块，答案加一

### 7.5 迷宫最短路

你做过的典型题：

- `练习5/A.cpp`

重点：

- BFS
- 记录前驱，用来还原路径

### 7.6 状态图 BFS

你做过的典型题：

- `练习5/B.cpp`：数字变换最少步数
- `练习5/C.cpp`：倒可乐 / 倒水问题

这类题的关键是：

- 一个“局面”就是一个状态
- 每次合法操作就是一条边
- 最少操作次数就是 BFS 最短路

### 7.7 回溯与剪枝

你做过的典型题：

- `练习5/D.cpp`：正方形
- `练习5/E.cpp`：素数环
- `练习6/A.cpp`：Sticks

常见剪枝：

- 排序后优先放大的
- 当前和超过目标值，立即停止
- 相同状态不重复搜
- 某一步失败且是对称情况，后面同类情况可直接跳过

### 7.8 Prime Ring

要点：

- 固定 `1` 在开头
- 每次填一个没用过的数
- 保证和前一个数之和是素数
- 最后一个还要和 `1` 相加是素数

### 7.9 Sticks

这是剪枝题代表。

要点：

- 枚举原始长度
- 小木棍先降序排序
- 拼一根失败时，尽量快速排除等价分支

这是“搜索优化”非常经典的训练题。

## 9. 数论基础

### 9.1 gcd

最常见性质：

- `gcd(a, b) = gcd(b, a % b)`

用途：

- 判断是否互质
- 化简比例
- 判断某些操作是否可达

### 9.2 欧拉函数 phi

定义：

- `phi(n)` 表示 `1..n` 中与 `n` 互质的数的个数

性质：

- 若 `p` 是质数，`phi(p) = p - 1`
- 若 `n = p1^a1 * p2^a2 * ...`
  则  
  `phi(n) = n * (1 - 1/p1) * (1 - 1/p2) * ...`

你做过的典型题：

- `练习6/C.cpp`

### 9.3 线性筛

用于：

- 筛质数
- 同时求欧拉函数

特点：

- 每个合数只被最小质因子筛一次
- 复杂度线性

### 9.4 容斥

你做过的典型题：

- `练习6/D.cpp`

核心思想：

- 先求总数
- 再减去不合法
- 注意交集重复计算，需要加回来

如果题目出现：

- “至少一个”
- “互质”
- “被若干数整除 / 不整除”

往往就要想容斥。

## 11. 动态规划总览

第七次课是考试高频。

### 11.1 什么是 DP

本质：

- 把大问题拆成小问题
- 小问题答案保存下来
- 避免重复计算

### 11.2 DP 三要素

每道 DP 题都先问自己三件事：

1. 状态是什么
2. 转移方程是什么
3. 初始值 / 边界是什么

### 11.3 DP 的两个重要性质

- 最优子结构
- 无后效性

如果一个问题不满足这两个性质，通常就不适合直接做普通 DP。

### 11.4 记忆化搜索 vs 递推

- 记忆化搜索：自顶向下
- 递推：自底向上

很多题两种都能写，但考试里通常递推更稳定。

---

## 12. 经典 DP 题型

### 12.1 数字三角形

你做过的典型题：

- `练习7/A.cpp`

状态：

- `dp[i][j]` 表示从 `(i, j)` 出发到底部的最大路径和

转移：

```cpp
dp[i][j] = max(dp[i + 1][j], dp[i + 1][j + 1]) + a[i][j];
```

### 12.2 最长上升子序列 LIS

你做过的典型题：

- `练习7/B.cpp`

朴素 DP：

- `dp[i]` 表示以 `a[i]` 结尾的 LIS 长度

转移：

- 枚举所有 `j < i`
- 若 `a[j] < a[i]`，则可以转移

复杂度：

- `O(n^2)`

### 12.3 最大子段和

你做过的典型题：

- `练习7/C.cpp`

核心思想：

- 以当前位置结尾的最优值，只和前一个状态有关

常见写法：

```cpp
now = max(0LL, now + x);
ans = max(ans, now);
```

如果题目规定“全负时答案为 0”，上面这种写法非常合适。

### 12.4 节目安排 / 区间选择

这类题常常和贪心、排序结合，也可能做成 DP。

重点关注：

- 按结束时间排序
- 能否选当前区间取决于前面最晚结束的位置

---

## 13. 背包专题

这是考试最常见的一类 DP。

---

### 13.1 0/1 背包

你做过的典型题：

- `练习7/D.cpp`

特征：

- 每件物品最多选一次

状态：

- `dp[j]` 表示容量为 `j` 时的最大价值

转移：

```cpp
for (int j = V; j >= w; j--)
    dp[j] = max(dp[j], dp[j - w] + c);
```

为什么倒序：

- 防止同一件物品被重复使用

---

### 13.2 完全背包

特征：

- 每件物品可以选无限次

转移：

```cpp
for (int j = w; j <= V; j++)
    dp[j] = max(dp[j], dp[j - w] + c);
```

为什么正序：

- 因为允许当前物品重复使用

---

### 13.3 分组背包

你做过的典型题：

- `练习7/E.cpp`

特征：

- 物品分组
- 每组最多选一件

核心：

- 处理一组时，要保证上一组结果不被当前组内其他物品重复连锁更新

常见写法：

- 先备份上一轮 `dp`
- 或者按组进行独立转移

---

### 13.4 多重背包

特征：

- 每件物品有个数限制

常见处理方法：

- 直接拆成若干件 0/1 物品
- 二进制优化拆分

## 15. 高频模板速查

### 15.1 BFS 最短路模板关注点

- 队列里放什么状态
- 是否需要 `vis`
- 是否需要记录前驱
- 是否有状态压缩

### 15.2 DFS 回溯模板关注点

- 当前层表示什么
- 哪些数 / 状态已经用过
- 结束条件
- 回溯恢复
- 剪枝条件

### 15.3 一维 0/1 背包

- 容量倒序
- `dp[j] = max(dp[j], dp[j - w] + c)`

### 15.4 完全背包

- 容量正序

### 15.5 LIS

- 朴素做法：`O(n^2)`
- 若范围更大，可拓展到二分优化 `O(n log n)`

### 15.6 最大子段和

- 当前和如果为负，直接舍弃

### 15.7 并查集

- `find`
- 路径压缩
- 关系更新公式要写对

## 16. 易错点总结

### 搜索类

- `vis` 没清空
- 多组数据没重置
- BFS 把状态写少了
- DFS 剪枝过头，剪掉了正确答案
- 忘记回溯恢复

### 动态规划类

- 状态定义不清
- 初始值错
- 转移顺序错
- `0/1` 背包写成正序，导致物品重复使用
- `long long` 没开导致溢出

### 并查集类

- 关系定义前后不统一
- 路径压缩后忘记更新关系
- 合并时公式方向错

### 数论类

- 质数判断边界错
- 线性筛数组范围不够
- 容斥符号加减写错

### 输出类

- 多打空格
- 多打空行
- `Yes` / `Yes!` / `yes` 大小写和标点不一致

## 18. 最后一份考前清单

做题前先问：

1. 数据范围多大？
2. 要最优值、方案数、可行性，还是最短步数？
3. 状态是什么？
4. 是图搜索、DP、还是数据结构维护？

写完后检查：

1. 数组范围够不够？
2. 要不要 `long long`？
3. 多组数据是否清空？
4. 输出格式有没有多空格、多空行？
5. 边界值：
   - `n = 1`
   - 全负数
   - 无解
   - 容量恰好装满

## 19. 一句话总结整门课

这 7 次课的核心，其实可以压成一句话：

> 先判断题目属于哪一类，再用这一类最稳定的模板去做，并在边界、复杂度、输出格式上收尾。

如果你已经把前面这些练习题都真正做通了，那么考试最重要的就不再是“见过没见过原题”，而是：

- 能不能快速识别题型
- 能不能写出正确模板
- 能不能稳住细节不失分

这也是这份复习文档最想帮你建立的能力。
